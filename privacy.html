《追光的小白球》隐私政策

运营主体：烬点工作室（邱**）
更新日期：2026年10月24日　生效日期：2026年10月24日

欢迎使用《追光的小白球》（以下简称“本游戏”）。本游戏由烬点工作室（邱**，以下简称“我们”）开发并运营。我们重视您的个人信息保护，并按照《中华人民共和国个人信息保护法》《中华人民共和国网络安全法》等相关法律法规处理相关信息。

请您在使用本游戏前仔细阅读本政策。您点击同意本游戏内的用户协议 / 隐私相关提示，或继续使用本游戏，即表示您已理解并同意本政策。

一、游戏基本说明

  • 本游戏为单机休闲玩法，核心进程可在本地运行。
  • 本游戏不设账号注册 / 登录，不收集姓名、手机号、身份证号等用于识别个人身份的信息。
  • 本游戏不提供内购支付。
  • 本游戏含广告（含激励视频等）。观看广告完全自愿；不观看不影响基本游玩，激励广告仅用于获得一次复活等可选收益。
  • 游戏设置、自定义故事与背景音乐等保存在您的设备本地，卸载游戏即可清除。

二、我们如何处理信息

2.1 本地存储的信息

下列信息仅保存在您的设备本地，我们不会主动上传或远程读取：

  • 游戏设置（如音效、音量、震动开关、难度等）
  • 您导入或粘贴的自定义故事文本、本地背景音乐相关记录
  • 您是否已同意用户协议等本地标记

2.2 广告及相关服务可能处理的信息

为在您同意本政策后展示广告，本游戏接入了第三方广告服务（TapADN / Dirichlet ADN）。广告服务可能根据其自身规则收集与设备、网络、广告展示相关的信息，例如：

  • 设备型号、操作系统版本、屏幕等设备信息
  • 设备标识相关信息（如 Android ID、OAID 等，具体以广告服务商实际采集为准）
  • 网络状态、IP 地址等网络信息
  • 广告加载、展示、点击、完播等交互信息

上述信息主要由第三方广告 SDK 处理，用于广告投放、反作弊、效果统计等。我们会在用户同意协议后再初始化广告 SDK。详细规则请以广告服务商公示的隐私政策为准。

2.3 发行 / 运行平台相关

若您通过 TapTap 等发行平台下载或运行本游戏，平台可能按其规则进行正版验证、实名认证、防沉迷等处理。相关信息由平台独立收集与处理，请同时阅读该平台的隐私政策。

三、第三方 SDK 说明

TapADN（Dirichlet ADN）广告 SDK

  • 使用目的：展示开屏 / 激励视频 / 插屏等广告
  • 提供方：与 TapTap / Dirichlet 广告联盟相关服务主体（以 SDK 官方说明为准）
  • 可能收集：设备信息、设备标识、网络信息、广告行为数据等
  • 隐私政策：https://ssp.dirichlet.cn/docs/agreement/
  • TapTap 平台隐私说明可参考：https://www.taptap.cn/doc/privacy-policy/

第三方 SDK 的信息处理由其自行负责。我们仅在实现广告展示所必要的范围内接入，并尽量在取得您同意后再启用。

四、信息存储与安全

  • 本地游戏数据受设备系统安全机制保护，我们无法远程访问。
  • 第三方 SDK 对其采集信息的存储地点、期限与安全措施，以其公示政策为准。
  • 我们不会出售您的个人信息。

五、您的权利

  • 因本游戏无账号体系，您可通过关闭广告观看、调整系统权限、卸载本游戏等方式停止使用相关服务并清除本地数据。
  • 您可在系统设置中管理相关应用权限（如网络等）。
  • 如您不同意本政策，请点击游戏内“不同意”并退出，或卸载本游戏。

六、未成年人保护

未成年人保护与防沉迷由发行 / 运行平台按规定执行。请监护人履行监护职责，合理安排游戏时间。连续游戏满 60 分钟时，本游戏会提示休息。

七、本政策的更新

我们可能适时更新本政策。更新后会在本页面公布，并在必要时通过游戏内提示等方式告知。若更新导致您的权利发生实质性变化，我们会再次征得您的同意（如法律法规要求）。
