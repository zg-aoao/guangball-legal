一、我们如何收集和使用您的个人信息

（一）我们如何收集您的个人信息

本游戏为单机休闲游戏，不设账号注册 / 登录，不提供内购支付。我们不会为注册、登录、实名认证或充值目的主动收集您的姓名、手机号、身份证号等身份信息。

1. 本地游戏数据

当您使用本游戏时，下列信息可能保存在您的设备本地，用于恢复设置与个性化内容，我们不会主动上传至自有服务器：

  • 游戏设置（音效、音量、震动与闪烁、难度等）
  • 您导入或粘贴的自定义故事、本地背景音乐相关记录
  • 您是否已同意用户协议 / 隐私政策等本地标记

如您不希望保留上述本地数据，可通过清除应用数据或卸载本游戏删除。

2. 游戏运行与网络访问

本游戏核心玩法可在本地运行。当您同意本政策后，为加载与展示广告，本游戏需要联网。为此，系统或第三方广告服务可能处理设备型号、操作系统版本、网络状态、IP 地址等与服务运行相关的信息。如您拒绝授予网络权限，广告功能可能无法使用，但不影响您进行基本游玩。

3. 广告服务

本游戏含广告（含激励视频等）。观看广告完全自愿；不观看不影响基本游玩，激励广告仅用于获得一次复活等可选收益。广告由第三方广告 SDK（TapADN / Dirichlet ADN）提供。在您同意本政策前，我们不会初始化广告 SDK。您同意后，广告 SDK 可能为广告投放、监测归因、反作弊与统计分析等目的处理设备信息、匿名设备标识、网络信息、应用运行信息及广告行为数据等。详细规则以其官方隐私政策为准。

4. 发行平台

若您通过 TapTap 等平台下载或运行本游戏，平台可能按其规则进行正版验证等处理。相关信息由平台独立处理，请同时阅读该平台隐私政策。

（二）设备权限调用情况

我们不会默认开启设备权限，仅在实现相应功能所必要时申请。本游戏主要涉及如下权限：

设备权限调用目的是否询问用户可否关闭
网络加载与展示广告、必要联网服务是（系统授权）可
读写存储 / 媒体文件（如系统需要）您主动导入本地故事或音频文件时读取所选文件是（系统授权 / 系统文件选择器）可

本游戏不因核心玩法申请麦克风、通讯录、摄像头、精确位置等权限。如您首次授权后希望关闭权限，可在系统设置中关闭。

（三）我们如何使用您的个人信息

  • 保障本游戏基本功能运行，保存您的本地设置与自定义内容；
  • 在您同意后提供广告展示及激励广告相关能力；
  • 改进产品体验、排查故障与保障服务安全稳定。

除非您清除本地数据、卸载应用或通过系统设置拒绝相应授权，本地设置类信息将在您使用本游戏期间保留在设备上。当我们需要将信息用于本政策未载明的目的时，将再次征得您的同意。

（四）其他规则

根据相关法律法规及国家标准，在下列情形中，我们可能依法处理相关信息而无需另行征得同意，包括但不限于：与履行法定义务相关；与国家安全、公共安全、重大公共利益直接相关；与刑事侦查、起诉、审判和判决执行等直接相关；为维护个人信息主体或其他个人重大合法权益但又很难得到本人同意；所涉信息由您自行公开或从合法公开渠道收集；为签订、履行您作为一方当事人的合同所必需；为维护所提供产品或服务的安全稳定运行所必需等。

二、我们如何保存您的个人信息

本地游戏数据保存在您的设备中，保存期限取决于您是否继续使用、清除数据或卸载应用。我们不在自有服务器上保存您的账号类个人信息（本游戏无账号体系）。

第三方 SDK 在中华人民共和国境内运营过程中收集和产生的个人信息，一般由其按照法律法规及自身政策保存在中国境内（为本政策之目的，不含港澳台地区），法律法规另有规定或取得您另行授权的除外。

保存期限届满或实现处理目的不再必要时，相关方应删除或匿名化处理相关信息（法律法规另有规定的除外）。

三、我们如何使用 Cookie 和同类技术

本游戏主要为本地运行的移动应用，不以浏览器 Cookie 作为主要数据处理方式。第三方广告 SDK 或 WebView 组件可能使用本地存储、SDK 标识等同类技术，用于广告服务、安全与统计分析。该等技术受第三方政策约束。您可通过系统设置、清理应用数据等方式限制或清除部分本地存储。

四、我们如何共享、转让、公开披露您的个人信息

委托处理 / 共享：为实现广告展示，我们会在您同意后接入第三方广告服务。该等第三方可能按其政策处理为实现广告服务所必要的信息。我们不会出售您的个人信息。

转让：我们不会将您的个人信息转让给任何公司、组织和个人，但在涉及合并、收购、资产转让或类似交易时，如涉及个人信息转让，我们将依法告知并要求继受方继续受本政策约束，或重新征得您的同意。

公开披露：除非法律法规明确规定或另行获得您的同意，我们不会公开披露您的个人信息。

根据法律法规，在与履行法定义务、国家安全、公共安全、刑事司法程序、维护重大合法权益、您自行公开或合法公开信息等相关情形下，可能依法共享、转让或披露而无需另行征得同意。

六、我们如何保护您的个人信息

  • 本地数据受设备系统安全机制保护；我们无法远程读取您的本地存档与设置。
  • 广告 SDK 仅在您同意后初始化；我们尽量控制权限申请范围。
  • 互联网环境并非百分之百安全，请您妥善保管设备并及时更新系统。

如发生个人信息安全事件，我们将按照法律法规要求及时采取处置措施，并以合理方式告知（难以逐一告知时可能发布公告），并依法向监管部门报告。

七、您如何管理您的个人信息

  • 访问 / 更正 / 删除本地数据：可通过游戏内设置调整偏好；清除应用数据或卸载本游戏可删除本地保存的设置与自定义内容。
  • 改变授权范围：可在系统设置中关闭网络等权限；关闭后，对应功能（如广告）可能无法使用，但不影响此前基于授权已完成的处理。
  • 撤回同意：可停止使用并卸载本游戏；因本游戏无账号，不适用“注销账号”流程。

如您无法通过上述方式行使权利，可通过本政策载明的邮箱与我们联系。为保障安全，我们可能需要先验证相关请求的合理性。对合理请求我们原则上不收费；对多次重复、超出合理限度或明显恶意的请求，可能予以拒绝。

在与履行法定义务、国家安全、公共安全、刑事司法、商业秘密等相关情形下，我们可能依法无法响应部分请求。

重大变更包括但不限于：服务模式发生重大变化；共享、转让或公开披露的主要对象发生变化；您参与个人信息处理方面的权利及其行使方式发生重大变化；我们的联系方式发生变化等。
